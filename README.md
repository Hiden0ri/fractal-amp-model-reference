# Fractal Amp Model Reference

Private reference archive for Fractal Audio FM9 / Axe-Fx amplifier models and their real-world counterparts.

## Documents

| File | Description |
|---|---|
| `documents/Fractal Amp Models and Drives.xlsx` | Offline export of the community-maintained amp and drive model spreadsheet. |
| `documents/1697700215206443.pdf` | Chinese FM9 owner's manual for firmware 3.x. |
| `documents/FAS_Amps Models Axe III Ares12.05.pdf` | Visual Axe-Fx III amplifier-model gallery for Ares 12.05. |
| `documents/Fractal Audio Amp Models - The Guide v1.0.pdf` | Yek's detailed guide to Fractal Audio amplifier models. |

## Preset Recipes

| File | Description |
|---|---|
| `presets/TS_DST_Pro22_Neck-Middle_Fender_Glass.md` | FM9 three-scene Fender clean recipe for a T's DST-Pro22 Carved neck-plus-middle blend. |
| `presets/TS_DST_Pro22_Govan_Fusion.md` | FM9 three-scene Suhr Badger 30-based fusion recipe for a T's DST-Pro22 Carved. |
| `presets/TS_DST_Pro22_Cornfed_Govan_and_Brit_JM45_Fusion.md` | Detailed FM9 Cornford MK50 II Govan-style Fusion and separate bright JTM45 Fusion recipes for a T's DST-Pro22 Carved. |
| `presets/7_String_Soldano_Ave_Mujica_Style.md` | FM9 Drop-A seven-string Soldano SLO-100 high-gain recipe inspired by Ave Mujica's modern J-rock/metal character. |
| `presets/TS_DST_Pro22_Tornado_of_Souls_Lead.md` | FM9 modified-JCM800 singing lead recipe for a T's DST-Pro22 Carved, based on analysis of a `Tornado of Souls` solo stem. |
