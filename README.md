# Fractal Amp Model Reference

Private reference archive for Fractal Audio FM9 / Axe-Fx amplifier models and their real-world counterparts.

## Documents

| File | Description |
|---|---|
| `documents/Fractal Amp Models and Drives.xlsx` | Offline export of the community-maintained amp and drive model spreadsheet. |
| `documents/1697700215206443.pdf` | Chinese FM9 owner's manual for firmware 3.x. |
| `documents/FAS_Amps Models Axe III Ares12.05.pdf` | Visual Axe-Fx III amplifier-model gallery for Ares 12.05. |
| `documents/Fractal Audio Amp Models - The Guide v1.0.pdf` | Yek's detailed guide to Fractal Audio amplifier models. |

## Notes

- The documents target different firmware generations, so model names and available models may differ from current FM9 firmware.
- For current information, cross-check the live Fractal Audio Wiki amp-model list.
